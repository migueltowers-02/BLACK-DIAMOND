# BLACK DIAMOND | Streetwear

Tienda virtual de ropa urbana desarrollada en HTML, CSS y JavaScript.

## Funcionalidades
- Catálogo de productos.
- Búsqueda y filtros.
- Selección de tallas.
- Carrito de compras.
- Administración de demostración.
- Diseño adaptable.

## Tecnologías
- HTML5
- CSS3
- JavaScript

## Importante
Este proyecto es una demostración frontend.
No procesa pagos reales ni utiliza una base de datos.
Los cambios realizados en la administración no se guardan permanentemente.
